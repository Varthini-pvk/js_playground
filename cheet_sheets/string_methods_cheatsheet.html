1. Basic Access & Substrings Core indexing & slicing

Immutable: all methods return new strings
JS TS typings Side‑effect free
Method Example TS Typing JS Typing Best Use
length "abc".length // 3 length: number property Validation, size checks, limits.
charAt "abc".charAt(1) // "b" charAt(index: number): string charAt(index) Legacy character access (prefer at or [i]).
at "abc".at(-1) // "c" at(index: number): string \| undefined at(index) Safe indexing, especially with negative indices.
slice "abc".slice(1) // "bc" slice(start?: number, end?: number): string slice(start, end) Preferred substring method, supports negatives.
substring "abc".substring(1, 3) // "bc" substring(start: number, end?: number): string substring(start, end) Legacy substring; avoid negatives, prefer slice.
⚠ Gotchas
  • substring(-1) is treated as substring(0) (negatives ignored).
  • slice(-1) returns the last char; substring(-1) does not.
  • charAt out of range → "", while at → undefined.

⚠ Gotchas
  • replace() only replaces the first match; use replaceAll() or a global regex for all matches.
  • repeat() throws a RangeError for negative or extremely large counts.
  • padStart()/padEnd() never truncate; they only pad when string is shorter than target length.

4. Parsing & Splitting Strings → arrays

Tokenization, CSV-like strings
JS TS typings
Method Example TS Typing JS Typing Best Use
split "a,b,c".split(",") // ["a","b","c"] split(separator?: string \| RegExp, limit?: number): string[] split(sep, limit) Tokenizing / parsing delimited strings or simple CSV-like data.
⚠ Gotchas
  • split("") returns an array of characters.
  • No separator: "abc".split() → ["abc"] (single element array).
  • split(",", 2) limits the array length to 2 items.

⚠ Gotchas

  • normalize() defaults to "NFC" if no form is provided.
Strings in JS/TS are immutable – all these methods return new values and never mutate the original.
